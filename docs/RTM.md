# RTM: матрица трассируемости требований Life Board MVP

## Идентификаторы

| Префикс | Что это | Где живёт |
|---|---|---|
| BG | Бизнес-цель | PRD, раздел Success |
| M | Метрика успеха, проверяется после релиза | PRD, раздел Success |
| US | Пользовательская история | User Stories |
| AC | Критерий приёмки: AC-n.k означает k-й критерий истории US-n | User Stories |
| FR / NFR / BR | Функциональное, нефункциональное требование, бизнес-правило | SRS, раздел 3 |
| TC | Тест-кейс: TC-n.k проверяет FR-n, TC-Nn.k проверяет NFR-n | Этот документ, матрица B |

Статусы требований и тест-кейсов: **Planned** (запланировано), **Partial** (реализовано частично), **Implemented** (реализовано, проверено вручную), **Passed** (автотест проходит).
